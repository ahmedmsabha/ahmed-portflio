# Ahmed Majdy Abu Sabha — Portfolio

Personal site: web and mobile work, the move into AI and machine learning, two degrees in progress, and an unfinished research paper.

```bash
npm install
npm run dev
npm run build
```

Set the public origin in `src/data/site.ts` (`siteUrl`) before deploying. The production build prerenders `dist/index.html` and writes `robots.txt` and `sitemap.xml` from that origin.
